🎙️ LibraMind AI Voice Assistant

Spec flow: Voice → Speech-to-Text → AI Assistant → Response → Text-to-Speech

Say something like: "Suggest beginner books for Machine Learning"

Uses the browser's built-in Web Speech API (Speech-to-Text + Text-to-Speech) — no external voice service required. Requires Chrome/Edge and microphone permission. Talks to the Task-7 chatbot at http://localhost:5007/api/ai/chatbot — make sure that server is running and you're logged in (see README).
