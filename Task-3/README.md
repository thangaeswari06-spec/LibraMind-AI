# Task 3 — Advanced CSS Styling and Responsive Design

**Objective:** Enhance CSS styling and make the webpage fully responsive.

## What's inside
- `index.html`, `dashboard.html`, `books.html` — Navbar + Sidebar + Dashboard + Book cards + Category pills + Search section.
- `style.css` — layout, cards, transitions, hover animations, CSS variables.
- `responsive.css` — breakpoints for tablet/mobile (sidebar collapses to a horizontal scroll bar, grid re-flows to single column).

## How to run
Just open `frontend/index.html` in a browser (no backend needed for this task). Resize the window / use dev-tools device mode to see the responsive behavior.

## Concepts demonstrated
- Multi-section complex layout (navbar, sidebar, main content)
- CSS transitions & keyframe animations (`fade-in`, card hover lift)
- Responsive design with media queries (no framework dependency, but structured like Bootstrap's grid philosophy)
